# Shivam Sharma — Portfolio

Responsive React portfolio featuring a live Three.js hero scene, animated project cards, scroll-linked progress, motion reveals, responsive navigation, skills, experience, education and contact sections.

## Run locally
```bash
npm install
npm run dev
```
Open the local URL printed by Vite, usually http://localhost:5173.

## Production build
```bash
npm run build
npm run preview
```

## Stack
React 18, Vite, Tailwind CSS, Three.js (React Three Fiber + Drei), Framer Motion, Lucide React.

## Customize
- Main content and project details: `src/App.jsx`
- Project cards: `src/components/ProjectCard.jsx`
- 3D hero scene: `src/components/Orb.jsx`
- Responsive styling: `src/index.css`
- Resume: `public/Shivam-Resume.pdf`

The hero download button uses the exact resume PDF supplied for this update.
